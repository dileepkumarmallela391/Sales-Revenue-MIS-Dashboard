# Sales & Revenue MIS Dashboard

## Project Overview
An interactive Microsoft Excel MIS dashboard built using a 100,000-row sales dataset to monitor business performance and support data-driven decisions.

## Key Features
- KPI cards for Total Sales, Total Profit, Profit Margin, Total Orders, and Total Quantity
- Interactive slicers for Year, Region, Category, and Ship Mode
- Monthly sales trend analysis
- Regional and category performance analysis
- Product sales and profit comparison
- Discount band analysis
- Year-over-year sales and profit growth
- Management insights and recommendations

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas
- Slicers
- KPI reporting and business analysis

## Project Files
- `Sales_Revenue_MIS_Dashboard.xlsx` — Excel workbook
- `dashboard-preview.png` — Dashboard screenshot

## Note
The project focuses on sales analysis, interactive reporting, and management insights using an available dataset. Data cleaning was not a primary component of this project.
